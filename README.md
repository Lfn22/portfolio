## 📋 Sobre o projeto

Site portfólio pessoal com seções de apresentação, projetos, certificados e currículo. Desenvolvido durante os cursos de **HTML e CSS da Alura** como segundo projeto prático.

## ✨ Seções

- 👤 Apresentação e bio profissional
- 🚀 Projetos desenvolvidos
- 📜 Certificados e formações
- 📄 Currículo para download
- 📬 Links de contato

---

## 🚀 Como rodar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/Lfn22/portfolio.git

# 2. Entre na pasta
cd portfolio

# 3. Abra no navegador
open index.html
```

---

## 🗂️ Estrutura do projeto

```
portfolio/
├── index.html              # Página principal
├── about.html              # Página sobre mim
├── cursoTrês.html          # Página de cursos
├── style.css               # Estilos globais
├── styles.css              # Estilos complementares
├── portfolio.css           # Estilos específicos
├── portfolio.js            # Interações JavaScript
├── js/data/                # Dados dos projetos
├── images/                 # Imagens do site
├── prints/                 # Capturas de tela dos projetos
├── certificados/           # PDFs dos certificados
├── curriculo.pdf           # Currículo para download
└── cartarecomendacao.pdf   # Carta de recomendação
```
